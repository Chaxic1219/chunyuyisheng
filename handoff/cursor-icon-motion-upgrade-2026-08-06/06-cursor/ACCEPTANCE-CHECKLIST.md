## 语义与覆盖

- [ ] 所有可点击控件均有明确语义图标或统一方向指示，包括 `AppButton`、原生 `button`、独立图标按钮、可点击列表行、卡片、页头和底部导航。
- [ ] 不同业务动作不存在错误共用图标：问用药/直接咨询、安全/退出/解绑、导出/删除、提醒/共享、服务包/服务中心/助手均已拆分。

## 交互、状态与可访问性

- [ ] 独立图标按钮触控区不小于 44×44px，并具有准确的 `aria-label` 或等价可访问名称。
- [ ] 默认、按下、处理中、成功、失败、禁用状态均有明确反馈。
- [ ] 请求处理中锁定按钮，连续点击提交、开通、发送和绑定操作只触发一次业务事件。
- [ ] 请求失败后按钮恢复可点击，成功与失败文字/图标含义明确。
- [ ] 状态切换不改变按钮宽度、卡片高度，不造成页面布局跳动。
- [ ] 普通动效只修改 `transform` 和 `opacity`，时长不超过约 240ms（持续加载除外）。
- [ ] 删除、退出、解绑不摇晃；使用 `danger` tone、明确文案和原有二次确认。
- [ ] 底部导航保持中央凸起布局，仅使用克制的颜色、透明度和不低于 0.98 的按压缩放，不使用弹跳或弹簧。
- [ ] 低动效模式关闭位移、缩放和结果上浮，保留颜色、文字、禁用和加载状态；实现不依赖 `prefers-reduced-motion`。
- [ ] 老年模式仅放大图标和点击区域，不额外加粗描边；普通、低动效、老年模式均符合规则。
- [ ] 带 `open-type` 的原生按钮仍保留原标签、事件、表单与授权行为。
