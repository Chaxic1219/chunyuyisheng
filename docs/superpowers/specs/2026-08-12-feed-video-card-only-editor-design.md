# 视频号仅卡片发送与采样编辑器设计

## 目标

视频号触发项只发送原生视频号卡片，不发送素材标题文字；后台视频号编辑器仅展示真机采样状态、封面预览和启用状态。

## 行为

- `feed_video` 响应不参与纯文本拼装，其他响应类型保持原样。
- 视频号素材未采样时不退化成普通链接；采样就绪后只调用原生视频号发送接口。
- 编辑器隐藏标题、视频号链接和封面 URL 输入框。
- 采样状态返回已采集的视频号名称、封面地址和采样时间，前端显示封面预览、状态与采样操作。
- 新建视频号素材允许空参数保存，内部名称自动使用“分组编号 视频号素材”，供后台列表识别。

## 验收

- 114 投递计划的 `replyText` 为空且包含一个 `feedVideo`。
- 编辑器无视频号标题、链接和封面 URL 输入项，并能显示已采集封面。
- 原有编号、小程序卡片和链接卡片回归测试通过。
