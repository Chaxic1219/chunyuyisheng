# 患者端医生归属：去掉上下线（2026-08-13）

## 目标
- 邀请链接进入 → 默认该医生
- 无邀请冷启动 → 最近使用医生
- 可切换医生列表 = 已建档绑定医生（复用健康服务页切换器）
- 去除后台「上下线」模块

## 非目标
- 不开放全平台医生浏览
- 不重做健康服务切换 UI

## 实现要点
1. `GET /api/bootstrap`：按 doctorId 时不再要求 `active=1`
2. 无参数时不再优先 `active=1`；可按 `lastDoctorId` 查询参数；否则任意医生兜底
3. 小程序本地 `lastDoctorId`：邀请成功/切换医生时写入；冷启动优先读取
4. 后台去掉上线按钮与状态列；`/activate` 返回 410 或兼容提示
5. 企微 `activeDoctorId`、周科普列表不再依赖 `doctors.active`
