# 设置页精简 — 设计规格

**日期：** 2026-08-06  
**状态：** 已批准（主人选 B + 1）  
**范围：** `patient-uniapp/src/pages/settings/index.vue`

## 目标

去掉占位项、重复说明与低频能力入口，设置页只保留真正可用的账号操作与一项本机提醒偏好。

## 保留

1. **消息与任务提醒**（单一开关）  
   - 开 = `medication/service/followup` 全 true  
   - 关 = 全 false  
   - 继续写入 `mpV32SettingsReminders`，结构不变  
2. **更换绑定手机号**（meta 显示脱敏号）  
3. **退出登录**  
4. **解除微信绑定**

## 删除

- 医生管家授权、助手上下文共享、账号安全（toast 占位）  
- 家属授权、导出/删除数据及申请列表、减少动效入口  
- 页头副文案、两条 AppNotice、「隐私与数据授权」整块  

## 不变

- 长辈模式在「我的」页  
- 家属走「家庭成员」  
- `reducedMotion` store 能力保留，仅去掉设置入口
