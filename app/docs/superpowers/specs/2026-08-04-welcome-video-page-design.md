# 入群欢迎 · 医生视频问候页（周/王）· 设计

**日期：** 2026-08-04  
**状态：** 已上线（2026-08-04）  
**范围：** 周玉春、王云程企微入群欢迎；极简 H5 播放页 + 链接卡  
**非范围：** 吕富靖及其它医生入群逻辑；联络表/808 欢迎卡本期不随周/王入群发送；后台可视化换片管理（可后续加）

## 背景

入群时现发欢迎语，并附带小程序卡（如 979/808 等）。主人希望周/王入群改为引导观看本地托管的医生问候视频：用户点企微链接卡进入极简播放页。

素材：

- 王云程：`微信视频2026-08-04_144938_263.mp4`（约 107MB）
- 周玉春：`微信视频2026-08-04_144837_521.mp4`（约 104MB）

## 已确认决策

| 项 | 选择 |
|---|---|
| 播放页内容 | 仅视频控件，无其它 UI/文案 |
| 入群附带内容 | 欢迎语 + 医患联络表 + 视频链接卡（不发 808） |
| 医生范围 | 仅周玉春、王云程 |
| 入口形态 | 企微链接卡 |
| 欢迎语文案 | 「小程序」改为「卡片」引导；保留「发 1 看功能」；去掉联络表引导句 |

## 方案

采用站内极简播放页 + 入群发链接卡（方案 A）。

### 1. 静态资源

部署到 nginx 可直出目录（与现有 `/assets/` 同口径，避免 SPA 回退吃成 HTML）：

| 医生 | 播放页 | 视频文件（压缩后） |
|---|---|---|
| 周玉春 | `/welcome-video/zhou.html` | `/assets/welcome-video/zhouyuchun-welcome.mp4` |
| 王云程 | `/welcome-video/wang.html` | `/assets/welcome-video/wangyuncheng-welcome.mp4` |

公网示例：`https://yht.chunyutianxia.com/welcome-video/zhou.html`

- 上线前用 ffmpeg 等压码，目标约 20–40MB（H.264 + AAC），原片可留备份不对外挂链。
- HTML：黑底、居中单个 `<video controls playsinline webkit-playsinline>`，`src` 指向对应 mp4；无标题、按钮、脚注。
- 不强行 autoplay（微信内常被拦截，依赖用户点播放）。

### 2. 医生配置

在周/王 `doctors.content`（或等价欢迎配置）增加：

```json
{
  "welcomeVideo": {
    "pagePath": "/welcome-video/zhou.html",
    "cardTitle": "周玉春主任视频问候",
    "cardDesc": "点击观看",
    "iconUrl": ""
  }
}
```

- `pagePath` 用相对路径；发送时用 `PUBLIC_ORIGIN` 拼绝对 URL（与链接卡深链纪律一致）。
- 无 `welcomeVideo` 的医生：入群逻辑不变（仍走现有 `welcomeWeappPayload` 等）。

### 3. 欢迎语文案

更新 `ZHOU_WELCOME` / `WANG_WELCOME` 及线上已发布 `groupWelcome` / 固定欢迎源：

- 删除联络表引导句。
- 「点击下方小程序观看…」→「点击下方卡片观看…视频问候」。
- 保留「发 1 查看群功能」类一句。

### 4. 入群发送链路

改动点：`fireGroupWelcome` → outbox `source=welcome` 投递路径（及任何对周/王欢迎附带卡的分支）。

对配置了 `welcomeVideo` 的医生：

1. 仍发欢迎文本（`@姓名` + 换行 + 正文；含联络表引导、发 1、视频卡片引导）。
2. 发医患联络表卡（`weappCodes: ["979"]`；未就绪则走既有 H5 链接卡兜底）。
3. 发一张 `sendLink` 视频页链接卡：`title/desc/url` 来自 `welcomeVideo`。
4. **不**发 808 医生介绍卡。

未配置医生：保持 `WELCOME_WEAPP_CODES`（979+808）等现行为。

### 5. 错误与回退

- 有 `welcomeVideo` 但缺文件/URL 非法：欢迎文本仍发；链接卡失败记 `cardErrors`，不阻断文本。
- 链接卡 `iconUrl` 空：走现有默认图标逻辑，不强行用大封面。

## 验收

1. 周群模拟入群：仅欢迎语 + 一张视频链接卡；无 979/808/主页小程序卡。
2. 王群同上，打开王片。
3. 点开卡：微信内黑底页仅视频，可播放。
4. 吕群入群：行为与改前一致。
5. 直接访问播放页 URL（非微信）：仍可播。

## 非目标（再强调）

- 不改患者端小程序 IA。
- 不做视频上传后台；换片靠替换静态文件 + 可选改配置。
- 不把 ~100MB 原片作线上主链；必须压码后再挂公网。
