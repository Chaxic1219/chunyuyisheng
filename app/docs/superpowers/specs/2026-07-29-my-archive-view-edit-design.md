# 我的档案 · 查看 / 更新双态

**日期：** 2026-07-29  
**状态：** 已确认  
**范围：** `patient-uniapp` 档案入口与 `/pages/archive/profile`；绑号回跳文案  
**非范围：** 健康记录页、后台 API 契约变更、新建路由  

## 目标

绑号后若档案已建立，进入**查看态**而非空表单；仅用户主动点「更新档案」才进入编辑。从未建档用户直接进入编辑态。入口改名为「我的档案」。

## 行为

| 条件 | 默认态 |
|------|--------|
| `hasProfile=true` | 查看：只读摘要 + 底栏「更新档案」 |
| `hasProfile=false` | 编辑：现有建档问卷（可预填手机号等） |
| 编辑提交成功 | 回到查看态并刷新 |

绑号 `returnUrl` 指向本页时：有档 → 查看；无档 → 编辑。

## UI 文案

- 导航 / 首页入口：**我的档案**
- 副文案：查看与更新基本信息、病史
- 查看底栏：**更新档案**

## 实现要点

- 单路由 `pages/archive/profile`，`mode: view | edit`
- 数据：`/api/mp/me` + `/api/mp/archive`（含 formPrefill）
- 同步：`pages.json`、首页 `assetItems`、相关 banner 文案
