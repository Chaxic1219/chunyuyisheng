# 春雨健康 · 视觉风格规格（患者端小程序）

## 品牌定位

长期健康管理工具感：冷静、可信、可执行；不是医院挂号大厅，也不是消费医疗电商。

## 色板（必须遵循）

| 角色 | Hex | 用途 |
|------|-----|------|
| Primary | `#176b52` | 主行动、选中态、关键图标 |
| Primary Dark | `#0c4535` | 深色顶栏、强调文字 |
| Soft Green | `#e5f3ec` | 浅底、卡片衬底 |
| Mint | `#cfe8dd` | 氛围光、渐变辅色 |
| Background | `#f3f4ef` | 页面底 |
| Surface | `#ffffff` | 卡片 |
| Ink | `#17201c` | 主文字（插画中少用文字） |
| Amber | `#936015` | 提醒/待办辅色（谨慎） |
| Soft Amber | `#fff1d6` | 提醒浅底 |
| Danger Soft | `#fbe8e5` | 异常浅底（异常插画可用极淡） |

## 造型

- 扁平到轻微软 3D；圆角友好（约 12–16px 意象），不要夸张拟物。
- 医疗意象：档案夹、血压计、药片、日历勾选、对话气泡、绿叶/十字**抽象化**，避免写实血腥/器械特写。
- 人物：中性、东亚成人侧影或半身剪影即可；不做夸张卡通表情。
- 助手头像：圆形构图友好；健康助手偏「专业温和」，生活管家偏「务实打理」。

## 技术

- PNG；插画可带透明背景；Hero 可用浅色实底。
- 小程序体积：单张建议 < 400KB；Tab/图标更小。
- 图标：居中、留边、线面清晰，在 81×81 与 48×48 仍可辨。

## 禁止

- Emoji、贴纸、霓虹、紫粉 AI 渐变、玻璃拟态炫光
- 图内任何可读文字、Logo 字标、水印、二维码
- 真实名人面孔、写实病患痛苦表情
- 与春雨无关的品牌标识
