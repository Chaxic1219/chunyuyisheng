核心功能

覆盖医患社群管理全链路，从患者入群到术后随访，一站式闭环

🧠

AI 智能分诊

三层风控引擎：本地红旗规则 + 症状哨兵 + LLM 天网。高风险恒走安全模板绝不自动发，低风险双闸验证后自动回复，中间态转人工。

💬

企微社群运营

企微群消息实时接入，编号指令精确响应，自然语言智能分诊。所有出站消息必须人工确认，零误发风险。

📋

患者建档与随访

医患联络表 → 自动建档 → 术后 SOP 随访。时间轴节点自动推进，宣教/复查/用药提醒精准触达。

📅

门诊加号与候补

线上加号申请 → 停诊日自动拦截 → 满号进入候补 → 释放时批量通知。支持家庭代办（子女为老人操作）。

🔗

春雨医生生态打通

小程序短链直达：图文咨询、视频问诊、预约就诊、我的订单。无需跳出企微，一键触达春雨服务。

👥

多角色权限体系

超级管理员 / 运营主管 / 医助 / 只读质检 四级角色。子管理员按医生维度隔离数据，多团队并行管理。

患者服务流程

从入群到康复的完整旅程

入群建档

患者扫码加入医生健康群 → 收到欢迎语+医生介绍 → 提交医患联络表完成建档

智能咨询

发送编号获取精准服务（门诊/加号/住院/科普）；自然语言描述病情 → AI 分诊分级 → 引导就医

预约就诊

线上加号申请 / 住院预约 → 医助跟进确认 → 就诊提醒

术后随访

选择随访方案自动入组 → 按 SOP 时间轴推送宣教/复查提醒 → 节点完成标记

口碑沉淀

患者评价医生 / 写感谢信 → 认证口碑墙展示 → 海报分享拉新

医疗级安全设计

五条不可违反的系统铁律

🚫

AI 绝不自动发高/中风险消息

高风险恒走安全模板，中风险必须人工审核确认后才发送

✋

企微出站零自动发

所有回复入 pending 队列，医助确认后才真正发送到群/患者

⬆️

风险只升不降

LLM 只能上抬风险等级，绝不能降级。本地规则是底线

🔐

回调鉴权 Fail-Closed

未配置密钥时一律拒绝所有外部回调，绝不裸奔

🛡️

PII 双向脱敏

患者信息 LLM 前脱敏 + 输出脱敏 + 公开展示脱敏，三层防护

📜

PIPL 合规

敏感信息单独同意 + 即时同意 + 最小字段收集 + 可申请删除

多角色协作
